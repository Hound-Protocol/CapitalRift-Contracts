# CapitalRift-Contracts
## Capital Rift · Private Contracts

Frontend-only roleplay contract maker. Click any text to edit it. **+ Stamp** adds a custom stamp (hover it to drag, recolor, rotate or delete); **Paper** and **Folder color** switch the dossier look; edits autosave in your browser; **Print / PDF** exports.

Design (dossier folder, page, stamps, stage, fonts) is copied from Hound Protocol joint-operations-web (code GPL-3.0-only; fonts SIL OFL, see `assets/fonts/`).

Pages: Settings → Pages → Deploy from branch → `main` / root.
